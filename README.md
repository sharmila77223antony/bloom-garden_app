# 🌸 BLOOM — Enchanted Glass Garden

A beautiful React web experience featuring glass-inspired flowers, magical seasons, dreamy galleries, and elegant animations.

✨ **Live Demo:** https://bloom-gardenapp.vercel.app/

## ✨ Features
- Glass-inspired UI and floral visuals
- Smooth animations and hover effects
- Flowers, seasons, gallery, and story pages
- Responsive design for desktop and mobile
- Elegant typography and visual effects

## 🛠️ Built With
- React.js
- Vite
- CSS
- Framer Motion
- Lucide React

## 🚀 Run Locally

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
cd bloom-garden
npm install
npm run dev
```
